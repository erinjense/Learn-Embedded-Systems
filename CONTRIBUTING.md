# Contributing

The full guide is in [docs/appendix/contributing.md](docs/appendix/contributing.md). The short version:

- **Do not make it longer without making it better.** Every added resource should replace a weaker one or live under "Go deeper."
- Fix dead links (run `python tools/check_links.py`), improve unclear checkpoints, and prefer free, current, authoritative resources.
- No link dumps, no affiliate links, no parallel tracks for other boards.
- Preview locally with `pip install -r requirements.txt` and `mkdocs serve`.
- Contributions are licensed CC BY-SA 4.0.
